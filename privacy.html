Privacy policy

rclone backup (personal) · last updated 18 October 2026

Who uses it

Only the owner of this Google API project, for their own household. No one else signs in with it.

What it accesses

With the drive.file permission, rclone can access only the files and folders it created in the owner’s Google Drive: the backup files it uploads. It cannot see other files.

What is collected or shared

Nothing. No data is collected, stored, sold or shared by this project. The backups go directly from the owner’s own server to the owner’s own Google Drive; the sign-in token stays on that server.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
