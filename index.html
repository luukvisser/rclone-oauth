rclone backup

A personal, single-household backup tool. Not offered to anyone else.

This Google API project lets rclone, the open-source file sync tool, upload one household’s own encrypted home-server backups to that household’s own Google Drive.

It uses only the drive.file permission: it can see and change only the files it created itself, and nothing else in the Drive.

There is no service, website or app for other users here. Only the owner of this project signs in with it.
